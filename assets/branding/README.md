# Recursos oficiales de Eco Solare

Subir los cuatro PNG originales, sin filtros, recortes ni cambios de proporción:

- `logo-horizontal.png`: encabezado en escritorio claro.
- `logo-minimo-color.png`: encabezado móvil claro y favicon claro.
- `logo-negativo.png`: encabezados oscuros, pie de página y favicon oscuro.
- `logo-isotipo-detallado.png`: anuncio del laboratorio en modo claro.

Los HTML detectan automáticamente la preferencia de color del navegador y conservan alternativas visibles si un PNG aún no está disponible.
